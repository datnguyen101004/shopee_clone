# Hướng dẫn & Quy chuẩn UI

- **Mô hình giao diện**: Code theo mô hình chuẩn Shopee Clone (giao diện, layout, màu sắc thương hiệu cam Shopee `#ee4d2d` / `#c2410c`, trải nghiệm tương tự Shopee).
- **Typography & Font chữ**: Thống nhất dùng font **Be Vietnam Pro** cho toàn bộ website (tối ưu hiển thị tiếng Việt hoàn hảo, dấu thanh rõ ràng, hiện đại).
- **Ngôn ngữ hiển thị**: Sử dụng **Tiếng Việt 100%** trên toàn bộ nội dung và nhãn giao diện người dùng, hạn chế tối đa tiếng Anh không cần thiết (trừ các thuật ngữ kỹ thuật đặc thù như SKU, JPEG, PNG khi bắt buộc).
- **Icon**: Sử dụng icon từ [Font Awesome](https://fontawesome.com/) (SVG components sắc nét, đồng bộ).
- **Thiết kế Responsive**: Bắt buộc tối ưu và hiển thị chuẩn xác trên 3 kích cỡ màn hình phổ biến:
  1. **Mobile (Điện thoại)**: `< 768px` (tối ưu cho kích thước 360px – 430px)
     - Thanh điều hướng thu gọn/dưới đáy hoặc cuộn ngang dạng chip/pill.
     - Bố cục 1 hoặc 2 cột cho danh sách sản phẩm, thao tác chạm thân thiện ngón tay (touch-friendly targets ≥ 44px).
  2. **Tablet (Máy tính bảng)**: `768px – 1023px` (tối ưu cho kích thước 768px – 1024px)
     - Bố cục lưới 3–4 cột cho sản phẩm, sidebar thu gọn hoặc dạng cột hẹp.
  3. **Desktop (Máy tính để bàn / Laptop)**: `≥ 1024px` (tối ưu cho 1200px – 1440px+)
     - Layout đầy đủ (header đa tầng, mega menu, sidebar cố định, lưới 5–6 cột sản phẩm).
